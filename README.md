# Simple Calculator

A sleek, keyboard-accessible web calculator featuring a frosted-glass UI, modular ES6 JavaScript architecture, and WCAG AA contrast compliance.

## Live Demo

- **Live Site:** [https://evancru-calculator.netlify.app](https://evancru-calculator.netlify.app) *(Update with your Netlify URL)*

## Features

- **Core Arithmetic:** Addition, subtraction, multiplication, and division with formatted two-decimal precision (`0.00`).
- **Safe Division Handling:** Prevents `Infinity` or `NaN` crashes by displaying `Result: Error (Div by 0)` when dividing by zero.
- **Full Keyboard Support:**
  - `Enter` — Unfocuses active number inputs to unlock global hotkeys
  - `+`, `-`, `*`, `/` — Triggers the corresponding math operation
  - `Escape`, `C`, or `R` — Clears all inputs, resets the result, and refocuses the first input
- **Modular Architecture:** Separation of concerns across pure calculation logic, keyboard event listeners, and UI orchestration.
- **Accessible & Performant:** WCAG AA color contrast (`#dc2626` clear button, `#38bdf8` operators), semantic landmarks, and minified `esbuild` production assets (100/100 Lighthouse scores).

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/cuduco19/calculator.git
   cd simple-calculator
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Build production assets:**
   ```bash
   npm run build
   ```

4. **Preview locally:**
   Open `index.html` using a local development server (such as VS Code Live Server).

## Deployment

Configured for static deployment on **Netlify** directly from GitHub:
- **Publish directory:** `.` (root)
- **Production assets:** Pre-bundled inside `dist/` via `esbuild`
